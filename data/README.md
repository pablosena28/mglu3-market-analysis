# Dados

O arquivo `raw/mglu3_2021.csv` contém a série diária utilizada no case de MGLU3.

Período: **4 de janeiro de 2021 a 30 de dezembro de 2021**.

Campos:

- `Date`: data do pregão;
- `High`: máxima do dia;
- `Low`: mínima do dia;
- `Open`: abertura;
- `Close`: fechamento;
- `Volume`: volume negociado;
- `Adj Close`: fechamento ajustado.

A base foi organizada a partir da planilha fornecida no exercício original. O projeto mantém o CSV necessário para tornar a análise reproduzível.
